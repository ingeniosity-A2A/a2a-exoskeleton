# a2a-exoskeleton-gitbook

Source for the A2A Exoskeleton Wiki. Each subfolder (`architecture/`, `core-systems/`, `intelligence/`) maps to a navigation group in GitBook. Content flows bidirectionally via Git Sync once configured.

## Structure

- `architecture/` — System design, capability primitives, GSAP orchestration, easeReverse rollback, no-GPU intelligence stack, benchmark validation
- `core-systems/` — Big Lake (DuckDB) and Quack Remote Protocol
- `intelligence/` — Query-of-Thought verification and Double Q-Learning stability
